# Zhaolan Huang — CV

A responsive academic CV site built with Jekyll and the
[Hacker theme](https://github.com/pages-themes/hacker).

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000`.

## Publish with GitHub Pages

1. Create a repository and copy this directory to its root.
2. Push to the repository's default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the default branch and `/ (root)`, then save.

The CV content lives in `_data/resume.yml`; edit that file to update the page.
