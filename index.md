## Career

### Freie Universität Berlin (2023 — Present)

**Research Assistant** @ Berlin, Germany  

- Ariel-ML: Rust-based TinyML framework featuring multi-core scheduling on microcontrollers.
- TinyDéjàVu: Eliminate up to 90% RAM usage on streaming inference. 
- msf-CNN: CNN fusion technique that achieves inference using 50% less RAM on MCUs.
- TinyChirp: Bio-acoustic TinyML pipeline that extended sensor lifetime from 2 to 18 weeks.
- RIOT-ML: Secure CI/CD for ML models on low-power devices based on IETF SUIT.
- U-TOE: TinyML benchmarking toolkit with RIOT OS support.
